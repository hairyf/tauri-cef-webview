## Default Permission

Default permissions for the cef-webview plugin. Allows the frontend to create and control embedded CEF webviews.

#### This default permission set includes the following:

- `allow-create`
- `allow-set-rect`
- `allow-set-visible`
- `allow-destroy`
- `allow-eval`
- `allow-insert-css`
- `allow-remove-inserted-css`
- `allow-navigate`
- `allow-reload`
- `allow-open-devtools`
- `allow-call`
- `allow-frame`
